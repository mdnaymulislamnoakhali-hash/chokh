- পিসি স্লিপ থেকে উঠলে সঙ্গে সঙ্গে ব্রেক দেখায় না; ব্রেক স্ক্রিন ৫ মিনিটের বেশি আটকালে নিজে বন্ধ হয়

## 🔜 পরের ধাপে আসবে
সাউন্ড, দৈনিক স্ট্যাটস, ক্রেডিট ফুটার, পূর্ণ সেটিংস পাতা (অটো-স্টার্ট, ভাষা, পানি/পশ্চার রিমাইন্ডার), অ্যানালিটিক্স।

## একবারের ইনস্টল (Windows)
1. **Node.js** LTS: https://nodejs.org
2. **Rust**: https://rustup.rs → `rustup-init.exe` চালান (ডিফল্ট ঠিক আছে)
3. **Visual Studio Build Tools** (https://visualstudio.microsoft.com/visual-cpp-build-tools/) → "Desktop development with C++" টিক দিয়ে ইনস্টল
4. WebView2 Windows 10/11-এ সাধারণত আগেই থাকে।
ইনস্টলের পর নতুন টার্মিনাল খুলুন।

## চালানো
```bash
cd app
npm install
npm run tauri dev      # পরীক্ষার জন্য (প্রথমবার Rust কম্পাইলে ৫-১০ মিনিট লাগতে পারে)
npm run build          # ইনস্টলার .exe বানাতে
```
বিল্ডের ফল: `app/src-tauri/target/release/bundle/nsis/Chokh_0.1.0_x64-setup.exe`
(সরাসরি চালানোর exe: `app/src-tauri/target/release/chokh.exe`)

`npm install` শেষে তৈরি হওয়া `package-lock.json` GitHub-এ কমিট করুন।
প্রথম `cargo` বিল্ডের পর `src-tauri/Cargo.lock`-ও কমিট করুন।

## দ্রুত পরীক্ষা (২০ মিনিট অপেক্ষা না করে)
- জানালার নিচের "ব্রেক স্ক্রিন কেমন দেখায়, দেখে নিন" লিংকে চাপুন, বা
- ট্রে আইকনে ডান ক্লিক → "এখনই ব্রেক নিন"।

## লোগো বসানো
এখন `src-tauri/icons/`-এ একটা অস্থায়ী আইকন আছে। আপনার লোগো হলে:
```bash
cd app
npm run tauri icon ../assets/logo.png
```
(লোগো ১০২৪×১০২৪ PNG, স্বচ্ছ ব্যাকগ্রাউন্ড)
