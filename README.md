# Chokh অ্যাপ (Tauri) — ধাপ ২

## এখন যা কাজ করে (ধাপ ২ + ৩)
- সিস্টেম ট্রে (বাম ক্লিক = জানালা, ডান ক্লিক = মেনু), ✕ চাপলে ট্রে-তে লুকায়, দুবার চালালে নতুন কপি খোলে না
- টাইমার: ১৫/২০/৩০/৪৫/৬০ মিনিট, ১ বা ২ ঘণ্টা বিরতি
- ফুল-স্ক্রিন ব্রেক ওভারলে (acrylic blur + গাঢ় স্তর, #E8F5E9 কার্ড), ৫টি র‍্যান্ডম মেসেজ, ২০ সেকেন্ডের কাউন্টডাউন, Skip / Esc
- নরম "টিং" সাউন্ড (মিউট করা যায়)
- কোণায় ও মূল জানালায় আজকের হিসাব: "আজ: ১২ বার রেস্ট, ৩ বার Skip" (`stats.json`, ৯০ দিন রাখে)
- সেটিংস পাতা: ইন্টারভাল, সাউন্ড, অটো-স্টার্ট, ভাষা (বাংলা/English), পানি (৬০ মি) ও বসার ভঙ্গির (৪৫ মি) নোটিফিকেশন
- ক্রেডিট ফুটার: সকাল ১০–১টা ও সন্ধ্যা ৬–১০টার জানালায় একবার করে, দিনে সর্বোচ্চ ২ বার, এলোমেলোভাবে
- অটো-স্টার্টে অ্যাপ লুকানো অবস্থায় চালু হয় (`--hidden`), জানালা লাফিয়ে ওঠে না
- নিরাপত্তা: পিসি স্লিপ থেকে উঠলে সঙ্গে সঙ্গে ব্রেক আসে না; ব্রেক স্ক্রিন ৫ মিনিটের বেশি আটকালে নিজে বন্ধ হয়

- বেনামী অ্যানালিটিক্স (ধাপ ৪): প্রথমবার `install`, দিনে একবার `app_open`, প্রতি ব্রেকে `break_taken` / `break_skipped`। ইভেন্ট আগে ফাইলে জমে, তারপর প্রতি মিনিটে ৫০টা করে পাঠানো হয়; অফলাইনে জমে থাকে (সর্বোচ্চ ৫০০টি), সার্ভার নিলে তবেই মোছে। প্রথমবার একটা ছোট নোটিস দেখায়, সেটিংসে বন্ধ করা যায়। বিস্তারিত: `../PRIVACY.md`

## ⚠️ বিল্ডের আগে দুটো লিংক বসান: `src-tauri/src/config.rs`
1. `FACEBOOK_PAGE_URL`: আপনার পেজের পুরো লিংক (`https://...`)। না বদলালে ক্রেডিটের লেখা আসবে, কিন্তু Follow বাটন আসবে না।
2. `TRACK_URL`: Supabase Edge Function-এর URL, যেমন `https://abcdxyz.supabase.co/functions/v1/track`। না বদলালে অ্যানালিটিক্স কোথাও পাঠানো হবে না।

এই ফাইলে `CREDIT_CHANCE_PERCENT` (এখন ৩০%) বদলে ক্রেডিট দেখানোর সম্ভাবনাও ঠিক করা যায়। দুটো লিংকই পাবলিক তথ্য, GitHub-এ রাখা নিরাপদ।

## অ্যানালিটিক্স পরীক্ষা
1. `TRACK_URL` বসিয়ে অ্যাপ চালান, নোটিসে "ঠিক আছে" চাপুন।
2. ~৫ সেকেন্ড পর Supabase → Table Editor → `analytics`-এ `install` ও `app_open` সারি আসবে।
3. ব্রেক স্ক্রিনে রেস্ট নিন বা Skip করুন (মূল জানালার "দেখে নিন" বাটন নয়, ওটা গোনা হয় না); ১ মিনিটের মধ্যে `break_taken`/`break_skipped` আসবে।
4. ইন্টারনেট বন্ধ রেখে কয়েকটা ব্রেক নিন, তারপর চালু করুন, জমানো ইভেন্টগুলো একসাথে আসবে।

## ক্রেডিট পরীক্ষা করবেন কীভাবে
মূল জানালার "ব্রেক স্ক্রিন কেমন দেখায়, দেখে নিন" লিংকে সবসময় ক্রেডিট দেখায়, আর ওই ব্রেক হিসাবে গোনা হয় না।
Follow বাটনে চাপলে ব্রাউজারে পেজ খোলে এবং ব্রেক শেষ হয় (রেস্ট বা Skip, কোনোটাই গোনা হয় না)।

## একবারের ইনস্টল (Windows)
1. **Node.js** LTS: https://nodejs.org
2. **Rust**: https://rustup.rs → `rustup-init.exe` চালান (ডিফল্ট ঠিক আছে)
3. **Visual Studio Build Tools** (https://visualstudio.microsoft.com/visual-cpp-build-tools/) → "Desktop development with C++" টিক দিয়ে ইনস্টল
4. WebView2 Windows 10/11-এ সাধারণত আগেই থাকে।
ইনস্টলের পর নতুন টার্মিনাল খুলুন।

## চালানো
```bash
cd app
npm install
npm run tauri dev      # পরীক্ষার জন্য (প্রথমবার Rust কম্পাইলে ৫-১০ মিনিট লাগতে পারে)
npm run build          # ইনস্টলার .exe বানাতে
```
বিল্ডের ফল: `app/src-tauri/target/release/bundle/nsis/Chokh_0.1.0_x64-setup.exe`
(সরাসরি চালানোর exe: `app/src-tauri/target/release/chokh.exe`)

`npm install` শেষে তৈরি হওয়া `package-lock.json` GitHub-এ কমিট করুন।
প্রথম `cargo` বিল্ডের পর `src-tauri/Cargo.lock`-ও কমিট করুন।
